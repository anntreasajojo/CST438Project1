## How to setup the app
### Cloning the App
* git clone https://github.com/anntreasajojo/CST438Project1.git
* Android Studio offers an easy way to clone repos, enter the link https://github.com/anntreasajojo/CST438Project1.git
* Download as zip, and open it in Android Studio
### Building the App
* Generate your own API key at [here](https://fdc.nal.usda.gov/api-key-signup#top)
* Reach out to any of the project maintainers listed above
* Once you have an api key, make sure you add "FDC_API_KEY=YOUR_API_KEY" in local.properties or gradle.properties on a new line
* FDC_API_KEY=jm1CkmTFOs3ywJpl3sCM3O6vlev4yg1IigaaggJ1
### Running the App
* Open the project in Android Studio and allow Gradle to sync. 
* Connect an Android device or start an Android Emulator.
* Select the app configuration in Android Studio.
* Press the Run button.

The app should build and launch after Gradle finishes syncing.
